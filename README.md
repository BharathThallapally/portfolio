# Bharath Kumar — Developer Portfolio

A responsive personal portfolio built with semantic HTML, CSS, and vanilla JavaScript. The design uses a calm **Mist Blue + Coral Pink** palette, with accessible navigation, subtle motion, project highlights, and responsive layouts.

## Portfolio sections
- Introduction and contact links
- About and technical skills
- Internship experience
- Featured projects, including MediTrack
- Hackathons and achievements, including Tech Horizon 2.0
- Certifications and participation
- Education and contact details

## Files
- `index.html` — page content and metadata
- `style.css` — layout, responsive styling, and Mist Blue + Coral Pink theme
- `script.js` — name typewriter, mobile navigation, active navigation state, and scroll reveals
- `assets/bharath-profile.jpeg` — profile photo
- `assets/resume.pdf` — downloadable resume

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Deploy with GitHub Pages
1. Commit the updated files to the `main` branch of the portfolio repository.
2. In GitHub, open **Settings → Pages** and confirm the deployment source.
3. Wait for the Pages workflow to finish, then refresh the live portfolio.
4. Check the page on mobile and desktop, and verify the resume and project links.

## Before publishing
Confirm that your resume is current and that project details, event participation, and certification names accurately reflect your experience.
