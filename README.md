# Bharath Kumar Portfolio

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — typewriter effect and mobile navigation
- `assets/resume.pdf` — place your final resume here

## Run locally
Open `index.html` in a browser or use VS Code Live Server.

## Before GitHub deployment
1. Put your final resume at `assets/resume.pdf`.
2. Replace the project placeholder links in `index.html` with actual GitHub/live-demo URLs.
3. Upload the files to the repository serving your GitHub Pages portfolio.
